# 毛主席语录 · 闪卡

保留原项目居中标题、红色底、金边竖卡、主题标签与进度条的版式。金边有缓慢流光，点击卡片切换语录。以 iPhone 17 的 402 × 874 CSS 像素作为主要检验视口，兼顾安全区、浏览器可用高度、窄屏和 Mac 居中阅读。超长卡片自然增高，页面可滚动；不会裁切文字。

## 操作

- 点卡片或「下一张」抽取下一条，优先未读，不连续重复。
- 「←」返回阅读历史，手机左右滑动切换。
- 「查看出处」展开语录来源和当前照片作者、许可、来源链接。
- 支持本地收藏、主题选择、阅读记录、添加到主屏幕与首次加载后的离线阅读。
- 页面空白处使用左右方向键、空格切换，S 展开出处；按钮保留原生键盘行为。
- 跟随系统减少动态效果设置，关闭金边流光与翻页动画。

## 本地运行与部署

运行 `python3 -m http.server 8080`，打开 `http://localhost:8080`。Cloudflare Pages 无需构建，发布仓库根目录。

## 景观与内容

五张照片分别为北京慕田峪长城、安徽黄山、广西桂林漓江、甘肃敦煌月牙泉、浙江杭州西湖。照片由 Wikimedia Commons 文件描述、作者和许可信息确认，原文件保存于 `assets/photos/`，无需访问随机图片服务；卡片显示正确地点名称。完整署名见 [PHOTO-CREDITS.md](PHOTO-CREDITS.md)。风景图仅为阅读背景，不表示语录写作地点或历史现场。

150 条原有语录存放于 `data.js`，来源文字沿用原项目，尚未完成逐条史料校验。收藏与阅读记录保存在本设备浏览器，不跨设备同步；浏览器禁止保存时仍可阅读。

## 缓存

`sw.js` 缓存整套静态文件和景观照片。每次更新静态文件时递增 `CACHE` 版本；旧页面关闭后新版本生效，避免混用不同版本的代码和数据。

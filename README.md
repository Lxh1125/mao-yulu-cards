# 知行 · 毛泽东语录闪卡

零依赖静态网页，可在 Mac、iPhone 浏览器中阅读；支持添加到主屏幕、首次加载后的离线阅读、收藏及阅读记录。收藏与记录保存在本设备浏览器，不跨设备同步。

## 操作

- 点击卡片或「下一张」抽取下一条；优先未读卡片，不连续重复。
- 「←」返回阅读历史；手机左右滑动切换。
- 「查看出处」展开原有来源；「收藏」保存当前卡片。
- 可按主题阅读，也可只读收藏。
- 页面空白处使用左右方向键、空格切换，S 展开出处。按钮保留原生键盘操作。

## 本地运行

运行 `python3 -m http.server 8080`，打开 `http://localhost:8080`。Cloudflare Pages 无需构建，发布仓库根目录即可。

## 配图与内容

`assets/` 中三幅山水 SVG 为项目原创装饰插画，不对应具体地点或历史事件。配图按卡片编号固定选择，随项目发布，无随机外链图、外部字体或图片 API 依赖。加载失败时隐藏图片，保留文字。

150 条原有语录统一存放在 `data.js`，来源文字沿用原项目，尚未完成逐条史料校验。

## 缓存

`sw.js` 缓存整套静态文件。每次更新静态文件时递增 `CACHE` 版本，旧页面关闭后新版本生效，避免混用不同版本的代码和数据。

# 毛泽东语录 · 精选60

从102条已对照公开著作转录本的语录中，精选60条用于随手阅读。选择依据见 [CURATION.md](CURATION.md)，原文链接和校对说明仍保留。

## 界面与操作

- iPhone 采用 `100dvh` 单张全屏闪卡，保留红底、金边及暗化国内景观。没有卡片外标题、工具栏或进度条；Mac 显示同款居中竖卡。
- 点文字或背景看下一条，优先未读且不连续重复；左右滑动，或点卡片内部底端箭头切换/返回。
- 文字下方中央的「喜欢」按钮点击标记、再次点击取消，不会触发翻页。
- 喜欢的卡片文字更亮更粗，金边加亮加粗；两者缓慢呼吸。系统开启减少动态效果时关闭动画，但保留亮度、粗细与实心心形的明显区别。
- 喜欢和当前位置保存在本设备浏览器；旧数据中的喜欢标记保留，不跨设备同步。存储受限时本次阅读仍有效。
- 卡片内部「出处」打开详情层，包含语录原文链接、校对说明、照片署名和许可。Esc 或关闭按钮退出。
- 支持主屏幕图标、首次加载后的离线阅读，以及方向键、空格阅读。

## 运行和部署

`python3 -m http.server 8080`，访问 `http://localhost:8080`。Cloudflare Pages 发布根目录，无需构建。每次静态资产变更时递增 `sw.js` 中的缓存版本，关闭旧页面后新版本生效。
